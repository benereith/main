# Flash-Bericht

Power-BI-Projekt (PBIP) für den Flash-Bericht des Group Controlling.

| Ordner | Inhalt |
| --- | --- |
| `Flash/` | Power-BI-Projekt: `Flash_Basis.pbip`, semantisches Modell (TMDL) und Bericht (PBIR) |
| `docs/flash-bericht.md` | Überblick, Fachlogik, Umbenennungen, Annahmen, Checkliste fürs erste Öffnen |
| `docs/modellreferenz.md` | Alle Tabellen, Spalten und Measures mit Beschreibung (aus dem TMDL erzeugt) |
| `docs/kommentare/` | Einrichtung der Kommentarfunktion (SQL, User Data Function, Button) |

Projekt öffnen: `Flash/Flash_Basis.pbip` in Power BI Desktop.
