# main

Power-BI-Projekt **MAP4 Prämientool** (PBIP).

- `MAP4-Praemientool/` – das PBIP-Projekt (Semantikmodell + Report)
- `MAP4-Praemientool/DATENMODELL.md` – Dokumentation des Datenmodells
- `tools/validate_model.py` – Konsistenzprüfung des Modells ohne Power BI Desktop

Öffnen: `MAP4-Praemientool/MAP4-Prämientool.pbip` in Power BI Desktop
(Vorschaufunktion „Power BI Project (.pbip)" muss aktiv sein).
